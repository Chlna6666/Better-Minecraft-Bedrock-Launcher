# gpui-hooks-macros

[中文](README.zh-CN.md)

Procedural macros used by `gpui-hooks`: `#[hook_element]` transforms a struct into a hooked
element with the required render/state plumbing, and `#[hook_render]` supports hooked render
implementations.

## Build and test

```powershell
cargo check -p gpui-hooks-macros
```
