# gpui-hooks-macros

[English](README.md)

`gpui-hooks` 使用的过程宏：`#[hook_element]` 把结构体转换为带状态/render 管线的
hooked element，`#[hook_render]` 支持 hooked render 实现。

## 构建与测试

```powershell
cargo check -p gpui-hooks-macros
```
